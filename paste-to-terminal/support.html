Paste to Terminal – for iTerm2

Questions or problems? Email apps@dalinis.com. Please include your macOS, Safari and iTerm2 versions.

Setting up

  1. Open the Paste to Terminal app. Its window shows three steps and ticks each one when it's done.
  2. In Safari, choose Safari → Settings → Extensions and tick Paste to Terminal.
  3. Set it to Allow on All Websites (Safari → Settings → Websites → Paste to Terminal, or click the extension's icon in Safari's toolbar).
  4. When macOS asks whether Paste to Terminal may control iTerm2, click OK.

Using it

Select text on a page, right-click, choose Paste to iTerm2, then the window and tab. The text appears in that tab as a paste. Press Return yourself when you're ready.

Common questions

The menu says "allow this website, or reload the page".
Paste to Terminal checks the page for hidden text before sending, and Safari only lets it do that on websites you've allowed. Allow it on all websites (see step 3 above). If you've just installed or updated the extension, reload pages that were already open.

The menu says "No iTerm2 windows open" or "Open iTerm2".
Open a window in iTerm2, or choose "Open iTerm2" from the menu, then right-click again.

Nothing arrives in iTerm2.
Check System Settings → Privacy & Security → Automation → Paste to Terminal, and make sure iTerm2 is switched on. The app's setup window shows this too.

A notice said "hidden text will be removed".
Part of what you selected was hidden on the page, for example white-on-white or zero-size text. Only the text you could see is sent. If you need the hidden part, copy and paste it by hand.

Why doesn't it press Return for me?
On purpose. Text from the web shouldn't run on its own. You read it, then decide.

Does it work with tmux?
Yes. Text goes to the active pane of a tmux session running in the chosen tab.

Does it work with Terminal.app or other terminals?
Not yet. This version supports iTerm2 only.
