Copy on Select – Auto Copy

Questions or problems? Email apps@dalinis.com. Please include your macOS and Safari versions.

Setting up

  1. Open the Copy on Select app. Its window ticks each step when it's done.
  2. In Safari, choose Safari → Settings → Extensions and tick Copy on Select.
  3. Set it to Allow on All Websites (Safari → Settings → Websites → Copy on Select, or click the extension's icon in Safari's toolbar).
  4. Reload any pages that were already open.

Using it

Select text with the mouse: drag, double-click or triple-click. It's copied as plain text and a "Copied" notice appears in the corner of the page. Paste anywhere with ⌘V.

Settings

Click the Copy on Select button in Safari's toolbar to:

  • turn it on or off everywhere;
  • turn it off for the website you're on;
  • also copy text selected inside text boxes and editors (off by default);
  • show or hide the "Copied" notice.

Common questions

Nothing is copied.
Check that the extension is on and allowed on the website (steps 2 and 3 above), that it isn't switched off for that site in the toolbar button, and reload the page.

How do I select text without copying it?
Hold Option while you select.

Selecting with the keyboard (⌘A, Shift+arrows) doesn't copy.
That's by design. Safari doesn't reliably tell extensions when a keyboard selection ends, so Copy on Select only reacts to the mouse. Press ⌘C as usual.

Text I select in a text box isn't copied.
Text boxes and editors are skipped by default, so selecting text you're editing doesn't overwrite your clipboard. Turn on "Also copy in text fields" in the toolbar button. Password fields are never copied.

Does it keep formatting?
No. It copies plain text, which pastes cleanly anywhere.
